# DigiCore Password Manager

A secure password manager application developed for DigiCore by Apps2U.

## Quick Start

```bash
python3 password_manager.py
```

## Overview

This application helps DigiCore staff securely store and retrieve login credentials instead of using insecure practices like sticky notes.

### Features

- **Add Credentials**: Store username, password, and URL/resource
- **View Credentials**: Display all stored credentials in a formatted view
- **Encryption**: All data is encrypted using ROT3 cipher
- **File Storage**: Persistent storage in a text file
- **Error Handling**: Robust input validation and error management
- **Menu-Driven**: Easy-to-use interactive menu system

## Project Structure

- `password_manager.py` - Main application (ready to run)
- `SETUP.md` - Detailed setup and usage guide
- `credentials.txt` - Auto-generated storage file (created on first run)

## Requirements

- Python 3.6+
- No external dependencies

For detailed setup instructions and usage guide, see [SETUP.md](SETUP.md)
